# FORM · Friend training journal

Separate chest/back/shoulder training log based on the supplied exercise list. The supplied working prescription is 4 sets of 12–15 repetitions per exercise. Two named supersets retain their original names and require their individual constituent exercises to be confirmed and logged separately.

The application supports offline recording, cloud synchronization, history, exports and rule-based review. Private records are segregated by server-validated access key and are not stored in this public repository. Browser keys and recovery drafts use a separate namespace from the original journal.

No access credential or server secret is included. This repository does not contain any user's training records or medical profile.
